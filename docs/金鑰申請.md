## 金鑰存在哪裡？安全嗎？

- 精靈把金鑰存在這台電腦的 `data/settings/integrations.json`（`data/` 整個資料夾不會進 git）。
- **Windows**：金鑰用系統內建的 DPAPI 加密，只有同一台電腦、同一個 Windows 帳號解得開；檔案被複製走也讀不出來。
- **Mac／Linux**：金鑰以明文存放，檔案權限設成只有你自己能讀（600）。請確保電腦有登入密碼、硬碟有加密。
- 存好之後，精靈畫面只會顯示「已設定」，**不會再顯示金鑰內容**（連最後幾碼都不顯示）。
- 精靈只有在**架設的這台電腦**上打得開（`127.0.0.1`），而且要用啟動器帶的一次性網址進入；就算服務開到外網，外面的人也打不開精靈。
- 雲端或 Docker 部署：不用精靈，直接在平台的「私密環境變數」設定下表的變數名稱即可（環境變數優先於設定檔）。

| 環境變數 | 內容 |
|---|---|
| `REA_SHARED_LINE_SECRET` | LINE Channel secret |
| `REA_SHARED_LINE_TOKEN` | LINE Channel access token |
| `REA_PUBLIC_BASE` | 對外網址，例 `https://rea.example.com` |
| `REA_ADMIN_USERS` | 管理員的 LINE userId（U 開頭 33 碼，多個用逗號分隔） |
| `REA_SIGNUP_MODE` | `invite`（預設，只限受邀）或 `open`（任何加好友的人） |
| `REA_PUSH_DRY_RUN` | 設成 `1`＝只模擬不送出：主動推播照流程跑但不連 LINE、不耗額度（紀錄在 server.log）。試跑新功能時建議先開 |
| `REA_SEARCH_PROVIDER`、`REA_SEARCH_KEY` | `brave` 或 `serper`，與其 API key |
| `REA_GSHEET_CUSTOMERS_URL`、`REA_GSHEET_LISTINGS_URL` | Google 試算表網址 |
| `REA_LVR_COUNTIES` | 實價登錄縣市，例 `台中市、宜蘭縣` |
| `REA_MOI_CLIENT_ID`、`REA_MOI_SECRET`、`REA_MOI_DAILY_LIMIT` | 地政平台金鑰與每日上限 |

**共通安全守則**

1. 金鑰不要傳到 LINE、Email、雲端硬碟，不要截圖給別人，也不要貼到 AI 聊天視窗。
2. 懷疑外流：立刻到該服務後台把金鑰**重新發行／刪除**，再用精靈貼上新的。舊的會立即失效。
3. 換電腦（Windows）：DPAPI 加密的金鑰帶不走，新電腦重跑一次精靈即可。

## 一、LINE 官方帳號（必要）

### 申請步驟

1. **建立官方帳號**：打開 [LINE Official Account Manager](https://manager.line.biz/) → 用自己的 LINE 登入 → 「建立新帳號」。名稱填你自己或店名（客人看得到），方案選「免費」。
2. **啟用 Messaging API**：官方帳號後台右上 **設定** → 左側 **Messaging API** → **啟用 Messaging API**。第一次會要你建立「服務提供者（Provider）」，名稱填你的名字即可。
3. **回應設定**：後台 **設定 → 回應設定**：**Webhook 開啟**、**自動回應訊息關閉**（否則客人會收到兩次回覆）。
4. **複製 Channel secret**：打開 [LINE Developers 主控台](https://developers.line.biz/console/) → 選 Provider → 選你的官方帳號（Channel）→ **Basic settings** 分頁 → **Channel secret**（32 個英數字）→ 複製。
5. **發行 Channel access token**：同一個 Channel 的 **Messaging API** 分頁最下面 → **Channel access token (long-lived)** → **Issue** → 複製那一長串。

### 填在哪裡

精靈「LINE 官方帳號」第 3 步，兩格分別貼上 → 按「檢查並儲存」。精靈會：

- 檢查格式（常見錯誤：兩把貼反、複製時斷行、貼到 Channel ID）
- 用 token 實際問 LINE「我是哪個官方帳號」，顯示帳號名稱就代表 token 正確
- 第 4 步請 LINE 實際打一次你的 webhook，**順便驗證 Channel secret**（secret 錯會顯示「簽章對不上」）

第 5 步「綁定管理員」：精靈給你 6 碼 → 手機加官方帳號好友 → 按「同意並開始」→ 傳「管理員 123456」。

### 費用

- 免費方案：每月 200 則「主動推播」；**回覆**使用者的訊息不算額度。本系統設計以回覆為主，每位仲介每天最多 3 則主動通知。
- 人多了可以在官方帳號後台升級方案，系統每天會自動向 LINE 查詢新的額度，不用改程式。
- LINE 台灣方案與價格可能調整，原則上以 [LINE 官方帳號方案說明](https://tw.linebiz.com/service/account-solutions/line-official-account/) 為準。

### 安全注意

- Channel secret 用來驗證「訊息真的是 LINE 送來的」；外流的話別人可以偽造訊息。access token 外流的話別人可以用你的帳號發訊息、花你的額度。
- 外流處理：Basic settings 的 Channel secret 旁按 **Issue**、Messaging API 分頁的 token 按 **Reissue**，再回精靈貼新的。
- 官方帳號後台的「加入群組或多人聊天室」建議關閉；本系統只服務一對一，被拉進群組會說明後自動退出。

## 二、對外 HTTPS 網址（LINE webhook 用）

LINE 要從網路連到你的服務，所以需要一個 `https://` 開頭的公開網址，指到 `http://127.0.0.1:8080`。

| 方式 | 適合 | 做法 |
|---|---|---|
| **Cloudflare Tunnel**（推薦） | 家裡或公司的電腦 | 照 [Cloudflare 官方教學](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/get-started/create-remote-tunnel/) 建通道，服務填 `http://127.0.0.1:8080`。需要一個放在 Cloudflare 的網域。 |
| 臨時試用 | 只想先試試 | 下載 `cloudflared`，執行 `cloudflared tunnel --url http://127.0.0.1:8080`，會拿到 `https://xxxx.trycloudflare.com`。**每次重開網址都會變**，要重跑精靈第 4 步，不適合正式使用。 |
| 自己的主機／VPS | 會架站的人 | Caddy 或 Nginx 反向代理到 8080，用 Let's Encrypt 憑證。 |
| **跟我們租** | 不想顧主機 | 見 [主機租用方案](主機租用方案.md)。 |

網址填在精靈 LINE 第 4 步（只要網域，例 `https://rea.example.com`），精靈會自動把 `…/line-shared/webhook` 填進 LINE 並測試。

**注意**：電腦關機、睡眠、斷網，LINE 就連不到；建議在 Windows 電源設定把「睡眠」改成「永不」，並執行 `python tools/start.py --autostart on` 讓服務開機自動啟動（背景執行，不跳視窗）。

## 三、591／樂屋新物件與海巡（搜尋服務 API key）

### 為什麼要搜尋服務？

591、樂屋等平台的服務條款**禁止爬蟲**。本系統不直接抓這些網站，而是用搜尋服務的官方 API 查「最近一天新出現的公開頁面」，只取標題、摘要、網址，使用者點連結回原網站看。每天的「今日報告」（找想買房的貼文＋各平台新物件）都靠它。

不串也可以：LINE 上的「今日海巡」會給你一鍵開啟的搜尋連結，只是要自己點。

### 申請（二選一）

**Brave Search API**

1. 到 [Brave Search API 後台](https://api-dashboard.search.brave.com/) 註冊並驗證 Email。
2. 選方案（免費或入門方案，需要綁信用卡；有每月免費額度）。
3. 左側 **API Keys** → **Add API key** → 複製。

**Serper（Google 搜尋結果）**

1. 到 [serper.dev](https://serper.dev/) 用 Email 或 Google 帳號註冊。
2. 註冊會送免費查詢次數；左側 **API Key** → 複製。

### 填在哪裡

精靈「591／樂屋新物件」→ 選服務、貼 API key → 「測試並儲存」（會實際查一次，用掉 1 次額度）。

### 費用與防呆

- 兩家都有免費額度，超過按查詢次數計費，原則上以官網價格為準。
- 系統預設全站每天最多 200 次（`REA_SEARCH_DAILY_CAP`）、每位仲介每天最多 40 次；同樣的查詢 2 小時內共用結果。
- 額度用完、金鑰錯誤、被限速 → 當天自動停用，不會重試轟炸。
- 建議在搜尋服務後台設定每月花費上限。

## 四、Google 試算表（不用金鑰）

1. 精靈裡下載範本（客戶需求、物件），到 [Google 試算表](https://sheets.new) **檔案 → 匯入** 上傳。
2. 照第一列欄位填資料。
3. 右上 **共用** → 一般存取權改 **知道連結的任何人**、角色 **檢視者**。
4. 複製網址列整串 → 精靈「Google 試算表」貼上 → 「檢查並儲存」→「立即同步」。

**安全注意**：「知道連結的任何人」代表拿到網址的人都看得到，所以**表裡只放需求條件和代號**（例：王先生→A001），不要放電話、身分證、地址。就算放了，系統也不會匯入這些欄位。網址本身也當成機密看待（精靈不回顯）。

之後每天早上 6 點後自動同步一次。物件表是「完整清單」：表裡刪掉的物件會視為下架（同仁在 LINE 上新增的物件不受影響）。

**店內物件表（全店共用模式）**：
- 欄位名稱可以用店裡習慣的叫法：委託編號、案名、區域、售價、型態、格局、權狀坪數、屋齡、負責同仁……系統認得常見的別名。
- 沒有「交易」欄的表一律當出售。
- 「負責同仁」填管理員面板登記的名字（管理員面板 →「仲介」→「改顯示名稱」），那間物件就算他的：他能在 LINE 上下架。
- 每天同步進來的**新物件**會配全店的買方，配到誰的買方就用 LINE 通知誰（一人一則，吃推播額度）。
- 屋主姓名、電話、地址、備註這類欄位整欄不匯入。

## 五、內政部實價登錄（不用金鑰）

政府開放資料，免申請、免費。精靈「實價登錄」勾選縣市 →「測試並儲存」，就能查行政區的成交概況（筆數、單價中位數、最近幾筆；排除備註有特殊交易的資料）。

- 資料來源：[內政部不動產交易實價查詢服務網・開放資料](https://plvr.land.moi.gov.tw/DownloadOpenData)，依政府資料開放授權條款使用。
- 每縣市每季下載一次，存在 `data/lvr/`，同一季不重抓。
- 只做概況參考，**不是估價**。

## 五之一、ToEstate 社區行情（建議）

同仁在 LINE 打「**行情 社區名**」「**行情 行政區**」就能查：社區近一年／三年單價、最近成交（樓層、房數、坪數、總價、單價）、成交備註的瑕疵提醒；行政區有成交量、單價中位、四分位、年變化、租金。

1. 精靈「實價登錄・行情」分頁 →「ToEstate 社區行情」。
2. 網址留空（預設 `https://toestate.tw/mcp`）。ToEstate 官方說明為免金鑰；有商用授權金鑰的填在「商用授權金鑰」（會用 `Authorization: Bearer` 帶過去，原則上以 ToEstate 提供的接法為準）。
3. 選「預設縣市」（只打「行情 南屯」時用哪個縣市）→「測試並儲存」。測試會實際查一次台中市南屯區。

防呆：每天最多 300 次（`REA_TOESTATE_DAILY_CAP` 可調）、同樣的查詢 6 小時內不重查、遇到限流（429）當天就停。ToEstate 連不上時，行政區查詢自動改用內政部開放資料（要先在下一節勾縣市）。不想用 ToEstate：網址填 `off`。

資料只供參考，**不是估價**；單價已扣車位，實價登錄約晚 1～3 個月申報。

## 六、內政部地政整合資訊服務共享協作平台（選用、付費）

### 這個做什麼

用「地政事務所代碼＋段代碼＋地號」查官方的**土地標示部**（面積、使用分區、公告現值等）。**不查所有權人**，也不會自動調閱謄本。

### 申請步驟

> 平台畫面、申請資格與審核流程可能調整，原則上以平台公告為準。

1. 打開 [地政整合資訊服務共享協作平台](https://cop.land.moi.gov.tw/) → 註冊會員（公司行號、事務所或個人），完成 Email 驗證。
2. 登入後申請介接服務，選「土地標示部」（依地號查詢），使用目的填「不動產經紀業務之物件資料核對」。
3. 等候審核；核准後到平台的應用程式／金鑰管理頁取得 **Client ID** 與 **安全碼（Secret）**。
4. 依平台規定儲值或繳費（按查詢筆數計費）。

### 填在哪裡

精靈「地政平台（選用）」→ 貼 Client ID、安全碼，設定每日上限 →「驗證並儲存」。
驗證只換通行證（access token），**不會查任何地號、不會扣錢**。

### 費用與防呆

| 設計 | 說明 |
|---|---|
| 要按「確認查詢」才查 | 第一次查某筆會先跳出「會收費」的確認鈕 |
| 同一筆只收一次 | 結果存在 `data/moi/cache.json`，再查同一筆直接用存檔 |
| 每日上限 | 預設 20 筆（精靈可改 1～500），到上限隔天才能再查 |
| 只在你的電腦 | 金鑰只存本機，畫面拿不到 |

### 常見錯誤

| 訊息 | 原因 |
|---|---|
| 地政平台不認得這組 Client ID／安全碼 | 複製錯、兩個對調、服務還沒核准、帳戶沒有餘額 |
| 平台回覆錯誤 | 地所代碼、段代碼或地號對不上；地所代碼與段代碼可在謄本或地政事務所網站查到 |
| 今天已達每日上限 | 隔天再查，或到精靈調高上限 |
