# 信義房仲小幫手（rea-kit 信義版）

給信義房屋分店用的 **LINE 店內小幫手**：同仁在 LINE 上記買方需求、新增物件，**全店的買方與物件互相配對**；
店內物件表每天自動同步；打「行情 社區名」直接查實價登錄行情。

> 本版改自開源專案 [rea-kit](https://github.com/Larryveryhandsome/rea-kit)（作者：林其衞／留白事務所，Apache-2.0）。
> 修改內容見 [CHANGES-信義版.md](CHANGES-信義版.md)；轉散布時請保留 [LICENSE](LICENSE) 與 [NOTICE](NOTICE)。

## 信義版多了什麼

| 功能 | 怎麼用 |
|---|---|
| **全店共用買方池** | 同仁新增物件 → 配到全店買方；配到別人的買方，卡片標「王先生（家儒的客人）」並 LINE 通知那位同仁。只有建立的人或店長能改。 |
| **店內物件表** | 串接精靈貼上店內 Google 試算表；認得委託編號、售價、權狀坪數等欄名，「負責同仁」欄決定物件歸誰。每天早上同步，新物件配到誰的買方就通知誰。 |
| **行情查詢** | LINE 打「行情 語山簷」「行情 南屯區」：ToEstate 社區行情（最近成交、樓層、坪數、單價、瑕疵備註提醒）；連不上自動改用內政部資料。 |
| **管理員面板** | 邀請同仁時填姓名、可改顯示名稱；店長可修改全店資料。 |
| **信義綠** | 卡片、精靈、管理員面板改信義綠；名稱可用 `REA_PRODUCT_NAME` 改。 |

### 上線前要先確認的事

- **公司規範**：客戶需求（暱稱、條件）會存在你架設的電腦或主機上，並透過店內自己的 LINE 官方帳號推播。請先確認信義的資訊安全與個資規範允許這樣使用。系統原則上不收電話、身分證、地址欄位。
- **LINE 推播額度**：免費方案每月 200 則。全店共用會多出「同事配對通知」，5 人以上的店建議留意額度（管理員面板首頁有用量）。
- **ToEstate**：程式照 ToEstate 公開的 MCP 端點寫，已用模擬伺服器測過；第一次請在串接精靈按「測試並儲存」實際連一次。

# 房仲自動化神器（rea-kit）

給台灣房仲、土地開發仲介、不動產業務的 **LINE 自動化小幫手**：在 LINE 上記買方需求、新增物件馬上配對、每天自動找「想買房的人」的貼文與各平台新物件。

## 快速開始（Windows，約 20 分鐘）

**需要**：Windows 10／11、[Python 3.10 以上](https://www.python.org/downloads/)（安裝時勾選「Add python.exe to PATH」）。

1. 下載本專案（綠色 **Code** 按鈕 → **Download ZIP**，解壓縮），或 `git clone`。
2. 在資料夾空白處按右鍵 →「在終端機中開啟」，安裝套件：
   ```bash
   python -m pip install -r requirements-server.txt
   ```
3. **雙擊 `開始設定.vbs`**：服務會在背景啟動（不會跳黑色視窗），瀏覽器自動打開「一鍵串接精靈」。
4. 照精靈的分頁一步步做：
   1. **LINE 官方帳號**（必要）：建帳號 → 開 Messaging API → 貼兩把金鑰 → 填對外網址並自動測試 → 用手機綁定自己為管理員。
   2. **591／樂屋新物件**（選用）：貼搜尋服務 API key，每天的自動海巡就會動。
   3. **Google 試算表**（選用）：貼試算表網址，客戶需求、物件自動同步。
   4. **實價登錄**（選用、免金鑰）：勾縣市就能查成交概況。
   5. **地政平台**（選用、付費）：貼 Client ID 與安全碼。
5. 手機打開你的官方帳號，打「功能」開始用。要讓同事一起用：手機打「管理員面板」→「仲介」→「＋ 邀請新成員」。

其他啟動方式：

| 想做的事 | Windows | 指令（任何系統） |
|---|---|---|
| 背景啟動 | 雙擊 `啟動.vbs` | `python tools/start.py` |
| 啟動並打開精靈 | 雙擊 `開始設定.vbs` | `python tools/start.py --setup` |
| 停止 | 雙擊 `停止.vbs` | `python tools/start.py --stop` |
| 開機自動啟動 | — | `python tools/start.py --autostart on` |

服務預設只開在 `http://127.0.0.1:8080`，LINE 透過你的 HTTPS 通道（例如 Cloudflare Tunnel）連進來。紀錄檔在 `data/logs/server.log`。

## 🔑 需要哪些金鑰？

只有 **LINE 官方帳號** 是必要的，其他都是選用。每把金鑰怎麼申請、填在哪裡、費用、安全注意事項，請看 **[docs/金鑰申請.md](docs/金鑰申請.md)**。

| 串接 | 金鑰 | 費用 |
|---|---|---|
| LINE 官方帳號 | Channel secret、Channel access token | 免費方案每月 200 則推播 |
| 對外網址 | Cloudflare Tunnel 或網域 | 通道免費 |
| 591／樂屋新物件、海巡 | Brave Search API 或 Serper API key | 有免費額度 |
| Google 試算表 | 不用金鑰 | 免費 |
| 內政部實價登錄 | 不用金鑰 | 免費 |
| 地政平台土地標示部 | Client ID、安全碼 | 約 1 元／筆 |

## 開發者

```bash
python -m pip install -r requirements-server.txt
python -m unittest discover -s tests -p "test_*.py"      # 全部用合成資料，不連真實網路
python tools/validate_skills.py                          # Skills 格式檢查
python tools/validate_cards.py                           # LINE 卡片格式自檢
python tools/pii_scan.py --all                           # 去識別化掃描（commit 前必跑）
```

| 目錄 | 內容 |
|---|---|
| `core/` | 品牌中立的業務邏輯（客需解析、配對評分、海巡貼文判斷、行政區字典） |
| `adapters/` | 外部串接：LINE、CSV、Google 試算表、實價登錄、地政平台、搜尋服務、本機設定檔 |
| `web/` | 服務本體：LINE webhook、串接精靈、管理員面板、服務條款、每日排程 |
| `skills/` | 房仲工作 SOP（Skills） |
| `tests/` | 全部用合成資料的測試 |
| `docs/` | 金鑰申請、主機租用方案、法遵範本、MCP 工具契約 |
| `tools/` | 啟動器、去識別化掃描、圖文選單、示範腳本 |

擴展性、安全性與串接失敗處理的檢視報告：[docs/擴展性與漏洞檢視.md](docs/擴展性與漏洞檢視.md)。

開發原則：程式碼裡零硬編碼的店名、人名、群組 ID、電話、地址；網路採集只走官方 API 或公開開放資料，有速率上限、遇到 429 即停；測試資料一律合成。詳見 [CLAUDE.md](CLAUDE.md)。

- LINE、Google、搜尋服務、地政平台的串接，都用本機模擬服務走完流程；**成功路徑還沒有用真實帳號實測**。第一次串接時，建議先開「推播只模擬」（`REA_PUSH_DRY_RUN`），確認後再正式推播。
