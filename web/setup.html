LINE 官方帳號

串好之後，你在 LINE 上就能「新增買方」「新增物件」、收每天的配對與海巡報告。全程大約 15 分鐘。

免費方案每月可主動推播 200 則；回覆訊息不算額度。原則上以 LINE 官方公告為準。

1建立 LINE 官方帳號（已經有就跳過）

  1. 打開 LINE Official Account Manager，用你的 LINE 帳號登入。
  2. 按 建立新帳號，帳號名稱填你自己或店名（客人會看到），類別選「不動產」。
  3. 方案選 免費 就可以，之後人多再升級。

2打開 Messaging API、關掉自動回應

  1. 在官方帳號後台右上角按 設定 → 左邊選 Messaging API → 按 啟用 Messaging API。
  2. 它會問「服務提供者（Provider）」：第一次就按建立，名稱填你的名字即可；隱私權政策網址可以先空著。
  3. 左邊選 回應設定：Webhook 打開、自動回應訊息關掉（不然客人會收到兩次回覆）。「聊天」可以留著，方便你自己手動回。
官方說明：Messaging API 入門

3貼上兩把金鑰

  1. 打開 LINE Developers 主控台（同一個 LINE 帳號登入）→ 點剛剛的 Provider → 點你的官方帳號（Channel）。
  2. Basic settings 分頁往下找 Channel secret（32 個英數字）→ 按旁邊的複製鈕，貼到下面第一格。
  3. 切到 Messaging API 分頁，拉到最下面 Channel access token (long-lived) → 按 Issue → 複製那一長串，貼到第二格。
✓ 金鑰已存在這台電腦（不顯示內容）。要換新的就直接貼上再按一次。

4設定 Webhook（讓 LINE 連到這台電腦）

LINE 要能從網路連進來，所以需要一個 https 開頭的對外網址，指到這台電腦的 http://127.0.0.1:8080。二選一：

  • A. Cloudflare Tunnel（免費、推薦）：照 Cloudflare 官方教學 建一條通道，服務網址填 http://127.0.0.1:8080，會得到像 https://rea.你的網域.com 的網址。
    只是試用的話，可以先下載 cloudflared 執行 cloudflared tunnel --url http://127.0.0.1:8080，會給一個 trycloudflare.com 的臨時網址；但它每次重開都會變，正式使用請用固定網址。
  • B. 自己的主機或 VPS：用反向代理（Caddy、Nginx）加 HTTPS，轉到 8080。
按下去會：① 把 網址/line-shared/webhook 填進 LINE ② 請 LINE 實際打一次測試 ③ 確認「Use webhook」已打開。

5用手機綁定你自己為管理員

  1. 按下面的按鈕，畫面會出現 6 碼。
  2. 用手機加你的官方帳號好友（官方帳號後台首頁有 QR code，或用 LINE 搜尋 ID @你的ID）。
  3. 它會傳歡迎卡給你 → 按 同意並開始。
  4. 再傳：管理員 123456（10 分鐘內有效）。

6誰可以用這個官方帳號？

預設只有你邀請的人能用，陌生人加好友不會用掉你的推播與搜尋額度。要加同事：手機打「管理員面板」→「仲介」→「＋ 邀請新成員」，把 6 位數碼給他，他加好友後傳這組數字就開始了（客人和物件要不要全店共用，看第 7 步）。

7全店共用買方與物件

店內同仁接同一個官方帳號時，建議用全店共用：大家新增的買方與物件放在同一個池子，同仁新增物件時會配到全店的買方，配到別人的買方會自動通知那位同仁。只有建立的人和店長（管理員）能修改或下架。

每個人的「匯出／刪除我的資料」只會動到自己建的客人和物件。切換模式時，已經建好的資料不會自動搬家，請在開始使用前決定。
